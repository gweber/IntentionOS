# Glossary

Short, shared definitions to reduce ambiguity.

## Intent

A one-sentence statement of desired change: **“Do X so that Y is true.”**

## Artifact

A concrete output that can be reviewed independently (doc, checklist, plan, decision record, release note, test case, etc.).

## Workflow

A repeatable sequence that converts intent into execution. One workflow is chosen per run.

## Role

A single mental lens (Strategist, Visioneer, Architect, Breaker, Curator). Only one role is active at a time.

## Memory

The append-only record of decisions, assumptions, and rejections that prevents relearning and compounds progress.

## Constraint

A rule treated as “physics” for the system: it limits options to preserve safety, clarity, and speed.

## Provider

An adapter to an external service or API. Providers should be safe and deterministic; avoid irreversible side effects.
