# Ops Quickstart (5 minutes/day)

This is a tiny daily routine to keep work aligned and compounding.

## Daily (≈5 minutes)

1. **Capture (1 min):** append any new intents to `docs/intent_inbox.md`.
2. **Select (1 min):** choose the *single* intent you will advance today.
3. **Pick workflow (1 min):** choose ONE workflow from `docs/workflows.md`.
4. **Pick role (30 sec):** activate ONE role from `docs/ai_roles.md` (default: Architect).
5. **Define artifact (1 min):** state what artifact you will produce by the end of the run.
6. **Run + log (30 sec):** after the run, record any decision/assumption/rejection in `docs/memory/*`.

## Weekly (≈15 minutes, optional)

- Review `docs/intent_inbox.md` for recurring themes.
- Promote repeated fixes into workflows/constraints.
- Prune tags and update glossary if new terms emerged.
